**MEIT LSTM 구조: A·B 독립 비판, 교차 검토, 설계 채택 — 2026-09-25**

**채택한 개발안은 B의 ‘수심·실측 마스크·관측 경과시간을 입력하는 단층 H64 LSTM + 마지막 입력 기준 잔차 15개 출력’이다.** A가 제안한 변경 효과의 분리 검증을 함께 채택한다. 이는 다음 구현·검증 대상으로 설계를 선정했다는 뜻이며, 새 모델의 성능 우승이나 운영 배포를 승인했다는 뜻이 아니다. 이번에는 운영 모델·학습 코드를 변경하거나 모델을 학습하지 않았다.

현재 코드와 train/validation 자료를 다시 읽고 A·B가 독립 검토한 뒤 상대 제안을 비판했다. 검토 대상의 LSTM은 다음과 같다.

```text
외부수심 z-score (B,30,1)
  → 단방향 LSTM(input_size=1, hidden_size=64, num_layers=1)
  → 최종 hidden (B,64)
  → Linear(64,15)
  → 미래 1~15분 수심 z-score (B,15,1)
  → m 단위 역정규화, 표시·평가 시 음수 0 제한
```

`meit_model/lstm.py:17–54`에서 확인했다. 총 파라미터는 **18,127개**다. 15개 미래 값을 한 번에 출력하며, 예측값을 재입력하는 자기회귀 decoder는 없다. hidden은 30개 입력을 모두 처리한 결과이므로 ‘마지막 수위만 보는 모델’이 아니다. 15개 출력은 동일한 비선형 encoder를 공유하므로 서로 독립된 모델이라는 비판도 맞지 않는다.

현재 forward/backward의 shape와 유한성은 정상이다. 저장소에 학습된 `.pt` 파일이 없어 과적합·과소적합·오차 개선을 실제 모델로 판정할 수 없었다. 세부 재현은 [diagnostics.py](diagnostics.py), 실행 결과와 파일 해시는 [diagnostics.json](diagnostics.json)에 있다. 최종 시험 분할의 성능은 측정하지 않았다.

학습·선택 목표의 차이는 합성 반례로 확인했다. 낮은 수위 99개와 높은 수위 1개를 둔 예에서 후보 P의 전체 MAE는 0.002000m로 Q의 0.002084m보다 작지만, 높은 수위의 과소예측은 P=0.20m, Q=0.05m다. 위험 가중 손실은 P=0.004000, Q=0.002584로 반대 순위를 준다. 이는 선택 기준 충돌의 가능성을 입증할 뿐, 실제 학습된 모델에서 이 문제가 발생했다고 입증한 것은 아니다.

**A와 B의 경쟁안 및 교차 반박**은 다음과 같다.

| | A안 | B안 |
| --- | --- | --- |
| 입력 | `(B,30,3)`: 수심 z, 실측 여부, 관측 age/180 | 동일 |
| 본체 | 단층 단방향 LSTM H32 | 단층 단방향 LSTM H64 |
| 출력 | 15시점의 q10/q50/q90, `(B,15,3)` | 마지막 입력 기준 잔차 15개, 최종 `(B,15,1)` |
| head | Linear(32,45) | Linear(64,15) |
| 파라미터 | 6,221 | 18,639 |
| 주요 목적 | 예측 분포의 일부를 표현 | 결측 정보 복구와 지속성 기준의 직접 전달 |
| 추가 비용 | 분위수 보정·경고 정책 재설계·손실 변경 | 3특성 데이터 경로 변경·잔차 대조 실험 |
| 결정 | 후속 후보 | 첫 구현·검증 설계로 채택 |

A는 `q50=z_last+Δ`, `q10=q50−softplus(a)`, `q90=q50+softplus(b)`를 제안했다. 이 방식은 같은 미래 시점에서 분위수 순서를 보장하며, 시간에 따라 수위가 반드시 상승하도록 강제하지 않는다. B는 불확실성을 표현한다는 장점에는 동의했다. 그러나 H32 축소·잔차·3분위수·pinball loss를 동시에 도입하면 개선 원인을 분리하기 어렵다고 반박했다. 또한 개별 시점의 q90을 15분 전체 경로의 임계 도달 확률이나 동시 예측구간으로 해석할 수 없다. 현재 위험 이벤트 자료에서 그 보정과 오경보 성능이 입증되지 않았다.

A는 B안에 대해 마지막 입력이 보완값일 수 있고, 잔차 구조도 불확실성 문제를 해결하지 못한다고 반박했다. B는 이를 수용하고 anchor의 의미를 명확히 하며 기존 데이터 품질 기준을 유지하기로 했다. 양측은 **B의 구조와 A의 단계별 대조 실험을 결합**하는 데 합의했다. A안의 유보 이유는 파라미터가 많아서가 아니다. A안은 오히려 더 작지만 출력의 의미·보정·경고 정책의 변경 범위가 크다.

채택 구조의 정확한 계산은 다음과 같다.

```text
x_t = [depth_z(t), observed(t), age_seconds(t) / 180]
h = LSTM(input_size=3, hidden_size=64, layers=1)(x_1 ... x_30).final_hidden
delta = Linear(64,15)(h)
prediction_z[k] = depth_z(30) + delta[k],  k=1...15
prediction_m[k] = max(0, mean_m + std_m * prediction_z[k])
```

- `delta[k]`는 마지막 입력 대비 k분 후의 변화량이다. 한 분 변화량을 누적 합산하는 방식이 아니다.
- 마지막 입력은 완료된 bin의 품질 검사를 통과한 인과적 수위 값이다. 현재 시각의 신선한 실측값과 동일하다고 부르지 않는다.
- 파라미터는 현재보다 512개, 약 2.82% 증가한다. skip 연결 자체는 파라미터가 없다.
- head를 0으로 초기화하면 초기 출력은 persistence와 정확히 같다. 임시 구조 검사에서 이를 확인했다. 첫 역전파에서는 encoder gradient가 0이고 head부터 학습된다. 이후 head가 바뀌면 encoder에도 gradient가 흐를 수 있다. 이 초기화는 persistence의 정확성이나 안전성을 보장하지 않는다.
- 초기안에는 층 추가·attention·dropout·시간축 단조성·곡선 평활화 제약을 추가하지 않는다. 마지막 둘은 실제 수위 하강이나 급상승을 잘못 억제할 수 있다.

구현에서는 `input_size=3`만 바꿔서는 안 된다. 현재 `cv.py:29–38,111–157`과 `train_lstm_cv.py:67–93`은 입력 품질 정보를 모델에 전달하지 않는다. `fold_scaling.py:64–74`는 X 전체를 수심으로 변환하므로 **기존 수심을 fold별로 변환한 다음** 마스크와 age를 붙이는 순서가 필요하다. 실측 마스크는 0/1, age는 초/180이며 두 채널에 수심 평균·표준편차를 적용하지 않는다. 기존 실측 수·공백·forward-fill·신선도 제한은 입력 승인 조건으로 유지한다.

학습·추론은 같은 feature 생성 함수를 공유해야 한다. predictor의 현재 단일 수심 목록 계약(`predictor.py:75–79,188–200`)도 버전 있는 3특성 계약으로 갱신해야 한다. 모델 파일에는 feature 순서, age 단위와 분모, fold scaler, 입출력 크기, residual 여부를 기록한다. 기존 표준화 X를 다시 정규화하거나 마스크를 수심으로 역정규화하면 안 된다.

권장 실험은 변경의 원인이 구분되도록 고정한다.

1. **구조만 비교:** C0=현재 F1·H64 절대값, C1=F3·H64 절대값, C2=F3·H64 잔차. 같은 masked MAE, 분할, seed, event-balanced sampler, 학습 예산과 checkpoint 기준을 사용한다. C0→C1은 품질 정보 효과, C1→C2는 잔차 효과를 평가한다. 여러 seed와 시간순 fold에서 결과를 비교한다.
2. **학습 목표를 별도 비교:** 선택된 구조에서 masked MAE와 기존 과소예측 가중치 2의 손실을 비교한다. 2는 기존 실험 상수이며 실제 안전 비용비가 검증된 값은 아니다. checkpoint 선택 기준의 변경 효과도 구분한다.
3. **집계 정의를 명시:** event-macro를 채택한다면 window별 관측 target 평균 → event 내 window 평균 → event 평균으로 고정한다. 이에 맞춘 학습은 window별 masked mean을 계산한 뒤 event-balanced sampling된 batch의 window 평균을 사용한다. 현재 batch 전체 유효 label 평균은 관측 label 14/15개에 따라 가중 방식이 조금 다르므로 별도의 변경으로 기록한다. 위험 검증 손실은 m 단위로 비교하고, operational metric에는 동일한 비음수 후처리를 적용한다.
4. **최종 개발 모델 선정:** 고정한 경고 정책에서 최소 5분 선행 경보, 오경보, 고수위 과소예측, event-macro MAE, horizon별·상승 구간·결측 유무별 오차를 함께 본다. 오경보 에피소드와 지속시간의 완전한 운영 평가는 정상 기간을 포함한 연속 자료가 필요하다. 평균 MAE 하나나 7/7이라는 소수 이벤트 결과만으로 통과를 선언하지 않는다.
5. **최종 시험 유지:** 구조와 경고 정책 선택은 개발 자료에서 끝낸다. 고정된 시험 분할은 최종 평가까지 사용하지 않는다. 같은 기간의 다른 센서·같은 호우 상관은 추가 검증해야 하며, 이벤트 ID 분리만으로 독립성을 가정하지 않는다.

기존 persistence와 명세가 명확한 선형 기준모델도 비교에 포함한다. 단순 선형 모델이 경쟁력이 있을 수 있다는 연구는 있지만 장기 예측 benchmark의 결과를 30→15분 수위 예측에 직접 일반화하지 않는다. Transformer로 바꾸면 더 좋아진다는 주장과 선형 모델이 반드시 이긴다는 주장 모두 현재 근거가 없다. [LTSF-Linear 원논문, AAAI 2023](https://ojs.aaai.org/index.php/AAAI/article/view/26317)

단층 LSTM에서 PyTorch의 내장 `dropout` 수치만 올리는 것은 적절한 대안이 아니다. 그 옵션은 LSTM 층 사이에 적용되므로 현재 단층에는 적용할 층 사이가 없다. 과적합 증거가 생기면 출력 dropout 등 별도 후보를 검증할 수 있다. 과거 30분 안에서만 양방향 처리를 하는 BiLSTM도 그 자체로 미래 정답 누수는 아니지만, 현재 추가할 근거가 확보된 것은 아니다. [PyTorch 2.11 LSTM 문서](https://docs.pytorch.org/docs/2.11/generated/torch.nn.LSTM.html)
