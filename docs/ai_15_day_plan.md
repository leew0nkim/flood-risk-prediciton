# AI A·B 15일 실행 계획

기간은 착수일 D1부터 D15까지이며, 하루 각 3~4시간의 작업을 가정한다. A/B는 역할 구분이며 특정 개인의 배정은 아니다. 기존 데이터 감사와 로직 설계를 바탕으로 구현부터 시작하는 계획이다.

AI A는 데이터 전처리·PC 수신·실시간 입력 처리·로그 관리를 맡는다. AI B는 모델 학습·파인튜닝·예측 및 위험 판단·성능 평가를 맡는다.

고정 사양: 1분 간격의 과거 30개 수위 입력으로 향후 1~15분의 수위를 매분 예측한다. 모델 구조 구현과 데이터 준비를 병행하고, 생성된 데이터로 모델을 학습한다.

전체 흐름: FloodNet 전처리·기본 모델 학습 → 실시간 예측 소프트웨어 연결 → 전달받은 축소모형 자료 전처리 → 파인튜닝·검증 → 모델·처리 설정 고정 → 새 최종 자료 평가 → 결과 정리·시연.

| 일차 | AI A: 데이터·연동 | AI B: 모델·평가 | 당일 완료 기준 |
|---|---|---|---|
| D1 | 기존 감사 결과를 전처리 규칙으로 정리. 폴더 구조·데이터 전달 형식 확정 | 모델 입출력·학습 방식·평가 지표 확정. 축소모형 자료의 필수 항목과 실험별 용도 규칙 작성 | 공통 규격과 데이터 요구사항 문서 |
| D2 | CSV 배열 해석, 숫자·단위 변환, 중복 처리, 불일치 기록 보류 목록 구현 | 현재 수위 유지·선형 예측 기준 모델과 LSTM 구조 구현 | 정리된 관측 테이블, 기준 모델과 LSTM 코드 |
| D3 | 1분 간격 처리, 긴 공백 분리, 이벤트·시간 기준 분할, 30분 입력·15분 정답 생성 | 학습 자료만으로 정규화 계수 생성. 데이터 로더·결측 정답 제외 손실·학습 루프 연결 | 학습 가능한 데이터셋과 학습 코드 |
| D4 | 샘플 수·결측·입력과 정답 시각 점검. 같은 이벤트의 분할 혼입과 미래 정보 사용 여부 확인 | 기준 모델 성능 측정, LSTM 첫 학습 및 학습 기록 저장 | 검증된 샘플과 첫 학습 결과 |
| D5 | PC 수신 프로그램, 1분 처리기, 최근 30분 버퍼 구현 | 검증 자료로 기본 모델 M0 선택·고정. 원본 시험 자료 평가와 오차 분석 | 기본 모델 M0·성능표·실시간 입력 처리기 |
| D6 | 측정 시각·센서값·상태·오류를 저장하는 기록 프로그램 작성. 파일 입력과 수신 입력 형식 통일 | 모델과 정규화를 함께 불러오는 예측 함수 구현. 예측 15개와 각 예측 시각 반환 | 수집 프로그램, 호출 가능한 예측 함수 |
| D7 | 과거 기록 재생으로 수신→버퍼→예측 호출→출력 로그 연결. 상태·작동 요청 메시지 형식 구현 | 현재 실내 수위와 실외 예측을 이용한 위험 상태·임계 도달 시간·작동 요청 판단 구현 | 입력부터 위험 상태·요청 출력까지 연결된 소프트웨어 |
| D8 | 전달받은 축소모형 개발 자료의 시간·단위·보정 정보·누락 확인 후 동일한 전처리 적용 | 축소모형 검증 자료에서 M0의 추가 학습 전 성능 측정. 파인튜닝 코드 준비 | 사용 가능한 모형 자료와 파인튜닝 전 성능 |
| D9 | 사전에 정한 실험 ID별 학습·검증 구분 적용. 모형 학습 샘플·마스크 생성 및 버전 저장 | 모형 학습 자료로 파인튜닝 M1 수행, 검증 오차에 따라 학습 중단 | 모형 학습 데이터셋과 파인튜닝 후보 M1 |
| D10 | M0·M1·기준 모델에 같은 입력을 전달하고 같은 시각의 결과를 저장하는 비교 실행 기능 구현 | 동일한 모형 검증 자료에서 M0·M1·기준 모델 비교. 상승 구간·임계수위 부근 오차 분석 | 파인튜닝 전후 비교표와 선택 근거 |
| D11 | 자료 부족·통신 지연·중복 수신 등 소프트웨어 오류 처리 확인. 전처리·통신·로그 설정 고정 | 최종 모델·정규화·위험 판단 설정 선택 및 고정. 최종 평가 항목 확정 | 최종 모델과 실행 설정 버전 확정 |
| D12 | 모델 고정 후 생성된 새 최종 자료 수신·검사. 실측과 예측의 시각 정렬 및 원자료 보존 | 고정된 모델의 1~15분 예측 오차·임계 도달 예측 평가 | 첫 최종 평가 결과 |
| D13 | 추가 최종 자료 취합. 누락·오류·예측 가능 구간을 확인하고 평가용 자료 확정 | 최종 자료 전체 평가. 실험별·예측 시점별·상승/하강 구간별 결과 정리 | 최종 성능표와 실패 사례 목록 |
| D14 | 데이터·전처리·수신·실행 코드를 묶고 재현 방법 작성. 전달 파일 누락 확인 | 실제값과 예측값 그래프, 기본 모델·파인튜닝 비교표, 한계와 결론 작성 | 재현 가능한 실행 묶음과 결과 보고 초안 |
| D15 | 동일 버전으로 소프트웨어 시연 실행·오류 확인. 최종 코드·데이터·실행 문서 정리 | 모델 및 성능 설명 정리, 발표 자료 완성, 최종 결과 확인 | 실행 가능한 AI 프로그램·모델·보고 자료 |

**일정에 필요한 입력 자료**

- D8까지 축소모형 개발 자료를 전달받는 것을 가정한다. 학습/검증 용도 규칙은 D1에 정하고, 해당 규칙에 따른 실험 ID 목록은 해당 기록을 검토하기 전에 확정한다.
- D12부터는 D11의 모델·처리 설정 고정 이후 생성된 새로운 최종 자료를 전달받는 것을 가정한다.
- 필요한 기록은 실험 ID, 실제 측정 시각, 실내·외 수위(m), 관측 상태, 보정 정보, 펌프·밸브 상태와 변화 시각이다. 시나리오와 데이터 용도도 함께 관리한다.
- 30분 입력과 15분 정답을 구성하려면 실제 45분 이상의 기록이 필요하다. 충분한 연속 기록과 관측 품질을 만족하는 구간만 사용한다.
- 개발 자료 전달이 늦으면 A는 기록 재생·전처리·오류 처리를, B는 공개 데이터 검증·예측 함수·파인튜닝 코드 준비를 먼저 진행한다. 자료에 의존하는 추가 학습·최종 평가 마감은 전달 시점에 맞춰 조정한다.

**A와 B의 인계 기준**

| 전달 | 내용 | 시점 |
|---|---|---|
| A → B | X(샘플 수,30,1), Y(샘플 수,15,1), 정답 관측 마스크, 이벤트/실험 ID, 시각, 분할 정보, 단위 | D3, D9 |
| B → A | 모델 파일·정규화 계수, 예측 함수, 미래 15개 시각·수위, 입력 부족·예측 가능 등 상태 | D6, D11 |
| A → B | 최종 원자료, 실측·예측 시각 대응, 결측·오류·버전 정보 | D12~13 |
| B → A | 최종 모델 버전, 성능표, 위험 상태·작동 요청의 출력 규격 | D11, D14 |

매일 마지막 15분에는 변경 파일·모델 버전·실패 사항·다음날 필요한 자료를 공유한다.

**구현·평가 기준**

- 기존 설계의 1분 처리·공백·관측 품질 기준을 유지한다. 입력 채움은 과거 값만 사용하고 정답 결측은 학습 손실과 평가에서 제외한다.
- 공개 자료는 이벤트·시간 기준, 축소모형 자료는 실험 ID 기준으로 나눈다. 같은 기록의 겹치는 입력 창을 학습과 평가에 섞지 않는다.
- 정규화는 공개 학습 자료로 계산한 계수를 저장하고, 초기 파인튜닝에서도 이를 유지한다. 검증·최종 자료로 계수를 다시 맞추지 않는다.
- M0는 FloodNet 기본 모델, M1은 축소모형 자료로 추가 학습한 후보를 뜻한다. 작은 데이터에서는 출력층 중심으로 추가 학습을 먼저 시도하고 검증에서 개선 여부를 확인한다. 개선되지 않으면 검증에서 선택한 M0 또는 기준 모델을 최종 버전으로 사용한다.
- 전체 오차뿐 아니라 1~15분 각 시점, 실험별 오차, 상승 구간 과소예측과 임계 도달 예측을 확인한다. 겹치는 창의 개수와 독립 실험 수를 구분해 보고한다.
- 30분 이력이 부족하면 예측 준비 중 상태를 출력한다. 현재 실측에 따른 위험 표시와 예측 상태를 구분한다. 향후 15분에 임계값 도달이 없다는 결과를 무제한 안전 시간으로 표시하지 않는다.
- 위험 판단과 작동 요청은 소프트웨어 출력으로 구현한다. 현재 수위·예측 수위·대피 미완료 입력·설정된 개방/종료 조건을 분리해 관리한다.
- D11 이후 최종 자료는 추가 학습이나 모델 선택에 사용하지 않는다. 그 결과를 보고 모델·전처리·판단 설정을 변경하면 변경 버전은 새로운 최종 자료로 다시 평가한다.

**D15 최종 산출물**

| AI A | AI B |
|---|---|
| 원자료 처리·1분 처리·샘플 생성 코드 | 기준 모델·LSTM 학습·파인튜닝 코드 |
| PC 수신·기록·실시간 입력·예측 호출 프로그램 | M0·M1 후보·최종 모델과 정규화 계수 |
| 데이터 분할·품질·실행 버전 기록 | 공개 자료 평가·모형 검증·최종 평가 성능표 |
| 실행 방법과 데이터 전달 문서 | 예측 그래프·실패 분석·발표 자료 |
